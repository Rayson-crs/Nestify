# Nestify

#### Description
**项目代号**：Nestify（中文名：纳斯特 / 巢整）
**项目类型**：基于 Electron 的跨平台（Windows/macOS）桌面 EXE 应用程序
**核心使命**：专治本地硬盘、移动硬盘及网络驱动器中的“文件杂乱综合症”，提供极速索引、细粒度批量重命名、智能自动归类与重复文件清理。
